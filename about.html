About this site

This is my personal College Algebra reference site — a place to collect the lessons I’m learning and make them easy to revisit.

👩‍🎓 Why I built it

I’m currently taking College Algebra. Instead of scattering notes across notebooks and screenshots, I’m organizing each topic here so I can review them anytime, and also help classmates who might need the same references.

📚 What you’ll find

Every lesson page contains a short summary, key formulas, examples, and practice problems. I update the site as I move through the course, so it grows with me.

🧠 My approach

I believe algebra becomes easier with consistent practice and clear references. This site is my tool for both — a study log and a quick-check resource before exams.

✨ A little more

I built this while learning GitHub Pages. The layout uses one shared style.css across all three pages, which keeps everything consistent and simple to maintain.
